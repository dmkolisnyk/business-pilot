# NextJS Frontend Skill

Use this skill for frontend structure, SaaS UX, pages, components, forms, and API client planning.

## Workflow

1. Group pages and features by domain.
2. Prioritize clear SaaS workflows over visual complexity.
3. Include loading, error, and empty states for data-driven UI.
4. Centralize API calls and keep secrets out of client code.
5. Validate forms and keep onboarding simple.

## Important Areas

Plan login, onboarding, WooCommerce connection, dashboard, analytics, recommendations, email campaign drafts, competitors, and settings.

## Rules

- Use reusable UI components without over-abstracting early.
- Make user-facing copy practical and decision-oriented.
- Do not expose WooCommerce credentials or backend secrets in frontend code.
- Align UI with the product goal: concrete business actions for store owners.

## Output

Return page structure, component responsibilities, states, copy notes, and API needs.
